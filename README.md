# MD Notes

A lightweight, elegant, customizable Markdown sticky notes utility built with Tauri

## ✨ Features

- Keyboard shortcut based note creation and manipulation
- Privacy first (files stored locally)
- Markdown syntax support
- Always on top option
- Create new note from clipboard

## 🛠️ Build locally

> Requires Rust, Node.js and npm/pnpm

- [Rust](https://www.rust-lang.org/tools/install) (stable)
- [Node.js](https://nodejs.org/) (LTS recommended)
- [npm](https://www.npmjs.com/)/[pnpm](https://pnpm.io/)

```bash
git clone https://github.com/YoavTC/md-notes.git
cd md-notes

npm install
npm run tauri build
# or
pnpm install
pnpm run tauri build
```
